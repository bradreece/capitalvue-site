# CapitalVue website

Static site for https://www.capitalvue.com.au, generated by a single Node
script and deployed to Netlify.

## Deploy in three commands

```bash
node build.js          # regenerates all 22 pages + style.css, sitemap, redirects, headers
# then drag this folder onto Netlify → Deploys, or use the Netlify CLI
```

There is no framework, no bundler and no dependency install step. `build.js`
is plain Node with no imports beyond `fs` and `path`.

## Everything is in build.js

`build.js` is the whole site. Page copy, nav, CSS, schema, redirects and the
results tables all live in it. Editing a page means editing `build.js`, not the
HTML.

The two exceptions are long-form article bodies in `content/`, which
`build.js` reads and injects, and the Netlify function in
`netlify/functions/`.

**`build.js` line 3 hardcodes an absolute path:**

```js
const DIR = '/home/claude/capitalvue-site';
```

Change it to wherever you clone this, or the build writes to the wrong place.
This is the first thing to fix on any new machine.

## What is source and what is generated

Generated on every build, do not hand-edit:

`*.html` (22 pages) · `style.css` · `sitemap.xml` · `robots.txt` · `ai.txt` ·
`llms.txt` · `_redirects` · `_headers` · `snapshot-email.js`

Source, edit these:

`build.js` · `content/*.html` · `snapshot-email.src.js` ·
`netlify/functions/submit.mjs` · `netlify.toml` · `assets/**`

## Guardrails already in the build

A licensure guard fails the build (exit 1) if any page claims a Western
Australian licence or market. CapitalVue is QLD and SA only and has never
bought in WA. Do not remove the guard.

## Netlify

Site ID `14ebdca3-fa0f-4a80-bcd1-32a236412fd8`, project `capitalvue-au`.
`netlify.toml` sets `publish = "."` and declares `netlify/functions`, so the
repo root is the deploy root.

After any deploy, confirm the function survived:

```
https://www.capitalvue.com.au/.netlify/functions/submit
```

Expect `{"ok":true,"version":"1.2.0",...}` with a `hardening` array. If the
`hardening` array is missing, an older build has overwritten the hardened
function and it must be rolled back.

See HANDOVER.md for open work and the things that will bite you.
